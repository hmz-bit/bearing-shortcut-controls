EXTERNAL VALIDATION ON THE PADERBORN RUN-TO-FAILURE DATA SET (time-varying load and speed), Zenodo record 10868257 (concept DOI 10.5281/zenodo.10805042), CC BY 4.0.
Written BEFORE any model was trained on this data and before any window was extracted. Not to be changed afterwards. Any later pipeline error: fix, rerun everything, report both versions.

Purpose: third and fourth frozen test of LF-PNCN (`base`) and of the phase 2 change `rowz_drop` against B1 (WDCNN on the fixed-Hz envelope spectrum), this time on REAL, naturally developed damage with RANDOM SPEED CHANGES between snapshots (set speeds 1500-3600 rpm). Nothing on this dataset is used to choose or change any method.

PREDICTION (stated before the result, not a result): if the "speed variation" explanation of the PU/CWRU versus UORED pattern is right, base and rowz_drop should beat B1 here (H2 supported for both). If B1 ties or beats them, as on UORED, that explanation is not supported by this dataset. No prediction is made for U2.

SOURCE FACTS (descriptor PDF by Aimiyekagbon, v2 2024-03-25, read in full; data inspected label-free): 17 experiments B01-B17, each one physical 61806-2RS ball bearing run from new until a failure criterion; "No defect was initiated in the bearings before the experiments." Snapshots of 1.6 s about every 12 s; the operating conditions (speed, loads) are redrawn at random between snapshots inside the per-experiment interval of descriptor Table 2. Accelerometers A (accHorizRear_A) and C (accHorizFrontal_C), 128 kHz (B01-B09) and 64 kHz (B10-B17), verified per file; the logs of the checked experiments give 10 g/V, gain 0 dB (all 17 logs are asserted in the build script). Defects found after dismantling (descriptor Table 3): B01 IR,OR,B; B02 IR; B03 IR; B04 IR,B; B05 B; B06 IR,B; B07 IR; B08 IR,B; B09 OR,B; B10 OR,B; B11 IR,OR,B; B12 IR,B; B13 IR,B; B14 B; B15 IR,B; B16 IR,OR,B; B17 B (IR inner race, OR outer race, B rolling element). Snapshot counts of all 17 experiments equal descriptor Table 3 and the M numbers are contiguous (checked from the zip central directories). The operatingConditions.csv of each experiment has exactly one row per snapshot (row i = snapshot M = i + 1).

GEOMETRY (descriptor Table 1): rolling circle DT = D = 35.5 mm, ball diameter 3.18 mm, z = 19; the contact angle is NOT stated, 0 is ASSUMED (deep-groove ball bearing). BPFO/f_r = 8.649, BPFI/f_r = 10.351 (computed by the code from the geometry).

DATA HANDLING CHOSEN A PRIORI (same for all three models):
 1. Channel: A (accHorizRear_A). The descriptor lists A first and does not rank the two channels; C is not used.
 2. Selection of snapshots (label-free, from the operatingConditions.csv and Table 2 only): a snapshot is IN-RANGE if its SET speed lies inside the Table 2 speed interval of its experiment (+-1 rpm; for B14-B17 2700 rpm). This removes the run-in at 750 rpm that fills the first snapshots of several experiments (for B01 and B05 the first 10% of ALL snapshots are entirely outside the range; verified label-free from the CSV) and protects against a speed-regime confound between healthy and faulty windows. Per experiment: healthy windows = the first 10% of the in-range snapshots (by snapshot index), faulty windows = the last 10% of the in-range snapshots; the 80% in between are a guard band and not used. At most 100 snapshots per end, evenly spaced by index (up to 200 were possible; 100 keeps the download near 5 GB and the effective sample is the bearing anyway). Resulting windows per end: B01 29, B05 52, B03 61, B12 77, all other experiments 100 (3038 windows in total; data/rtf/selection.csv, results/rtf/selection_summary.csv).
 3. Labels: healthy windows are 0 for all labels. Faulty windows carry the Table 3 defects of their experiment: IR = 1 for B01,B02,B03,B04,B06,B07,B08,B11,B12,B13,B15,B16 (12 bearings); OR = 1 for B01,B09,B10,B11,B16 (5 bearings; there is NO outer-race-only bearing: all five also have rolling-element damage and B01, B11, B16 also inner-race damage). Ball defects are not a target: windows of ball-only or ball-plus-other bearings are negative for the label that is absent (as ball was handled on PU and UORED). B05 (ball only, deliberately interrupted) and B14, B17 (ball only) are negative for IR and OR at both ends, so their labels do not depend on whether their last snapshots are really faulty. B01 and B16 (no failure criterion preset) are treated like all others (rule above). The defect onset time of every bearing is unknown, so some faulty-end windows may be taken before the documented defect existed (label noise, stated as a limitation).
 4. Window: the FIRST 1 s of the 1.6-s snapshot (128000 or 64000 raw samples), converted with 10 g/V, resampled with resample_poly to 42 kHz (21/64 for 128 kHz, 21/32 for 64 kHz) = 42000 samples; one window per snapshot.
 5. Shaft frequency: f_r from the measured meanAbs_speed of the snapshot if it agrees with the set speed within 3%, otherwise from the SET speed. Basis (results/rtf/speed_check.txt, 102 sampled snapshots, shaft line searched in the 1-s Welch spectrum, label-free): measured and set speeds agree to within about 0.5% for all experiments except B04, where the measured speed is exactly half of the set speed and the shaft line sits at the set speed (so the set speed is used for all B04 snapshots); at B10 snapshot 54 and B16 snapshot 5891 the measured speed is about 1 to 3 rpm (invalid, set speed used). The shaft line is weak in the later experiments (prominence 0.3 to 40 times the median level for B07-B17), so the speed columns could not be verified independently there; this is a limitation.
 6. LF-PNCN input: the frozen order tensor (3 bands 500-2500, 2500-5000, 5000-10000 Hz, 5 harmonics, 64 xi points, Delta rule) with the geometry above and the per-snapshot f_r; windows have 42 kHz so the frozen code path is unchanged. Variants `base` and `rowz_drop` exactly as in scripts/phase2/variants.py, PU Tier 1 configuration (lr 1e-3, batch 64, weight decay 1e-4, 40 epochs), seed = split number, standardiser from training windows only. Trained on the CPU (2 threads, several processes).
 7. B1: own WDCNN implementation (work/scripts/b1: envelope spectrum band-pass 500-10000 Hz order 12 on the 42 kHz window, 21000 bins, WDCNN with 2 outputs [IR, OR], BCE-with-logits), PU recipe: Adam lr 1e-3, batch 32, 30 epochs, per-window gain |N(1, 0.3)|, global normalisation = division by the std of the raw (g-scaled, resampled) samples of the training windows, seed = split number, last epoch scored. DEVIATIONS (declared in advance): (a) random 1-s crops are not available (only the selected 1-s windows exist), so each epoch draws 800 windows (25 batches of 32) without replacement from the training windows, giving 750 optimisation steps per split, comparable to the PU recipe (about 27 batches x 30 epochs); (b) the std comes from the selected training windows, not from the whole recordings; (c) 2 outputs instead of the 3 of the PU model recipe; (d) B1 is trained on the GPU. Caveat: this B1 recipe is the PU recipe, not tuned for this dataset (the LF-PNCN family is not tuned either).
 8. Splits: 100 bearing-wise splits, 11 training and 6 test bearings, drawn uniformly without replacement from the set of all C(17,6) = 12376 test sets that satisfy: the test set contains at least 1 OR-positive and at least 1 IR-positive bearing, and the training set contains at least 2 OR-positive and at least 2 IR-positive bearings (11110 of 12376 satisfy it). Seed: numpy default_rng(20261028). Split numbers 5..104; the same splits for all models. All windows of a bearing (healthy and faulty end) are on the same side.
 9. Metric: for each split, the pooled-window AUROC of the IR score and of the OR score over all windows of the six test bearings (positives = faulty windows with that defect label; negatives = every other window of the test bearings, including the healthy windows of the same bearings and the windows of bearings that lack that defect); Macro = mean of the two; mean over the 100 splits.
 10. Statistics: paired bearing-level cluster bootstrap, B = 2000, same draws for all models (seed 0); the cluster is the physical bearing (each bearing contributes its healthy and faulty windows); resampling with replacement inside two strata (the 5 OR-positive bearings and the 12 other bearings); weighted-AUROC fast path (as in scripts/uored/analyze_uored.py, generalised to 17 bearings) verified against sklearn; 95% percentile intervals; splits in which a label loses all its positives or negatives are skipped for that replicate.
 11. Descriptive analyses (no decision rule): per-bearing AUROC for every OR-positive and IR-positive bearing (faulty windows of that bearing against all negatives of the splits in which it is a test bearing); and a LIFE-STAGE CONTROL: the same Macro-style AUROC with negatives restricted to the faulty-end windows of bearings that lack the defect (late-life negatives only: for OR the late windows of the 12 non-OR bearings; for IR the late windows of the 5 non-IR bearings B05, B09, B10, B14, B17), which tests fault-type discrimination independently of "early versus late life".
 12. Negative controls (all three models): (i) bearing-label permutation on the first 20 splits (5..24), 2 permutations each: the (IR, OR) faulty-end label pair of each of the 17 bearings is reassigned to a different bearing at random (healthy windows stay 0; a permutation is redrawn, at most 20 times, until every training and test set still has both classes for both labels); expected held-out Macro about 50, a mean above 56 for any model would indicate leakage or identity memorisation; (ii) train-versus-held-out gap: the window-level Macro-AUROC on the training windows is recorded in every split and reported next to the held-out value.

PRE-STATED DECISION RULES (reported whatever the outcome):
 U1: each variant's Macro bootstrap 95% lower bound > 50.
 U2: rowz_drop minus base: confirmed if > 0 with the CI lower bound > 0; inconclusive if the point estimate >= 0 and the CI includes 0; not reproduced if < 0.
 H2: for each of rowz_drop and base versus B1: supported if the difference > 0 with the CI lower bound > 0; inconclusive if the point estimate >= 0 and the CI includes 0; not supported if the point estimate < 0; the literal +6 point threshold is reported as met or not met on the point estimate.
 No hyperparameter or variant is changed, added or removed after seeing results.

KNOWN LIMITS AND CAVEATS (stated in advance): the labels of run-to-failure data are defined by early and late life, so a model may partly learn life stage instead of fault type (controlled only by the in-range speed filter, the guard band and the late-life-negatives analysis in item 11; NOT controlled: drifts of vibration level, load, temperature and mounting with age, differences between experiments); no outer-race-only bearing exists, so OR performance mixes with ball and inner-race damage; only 5 OR-positive and 12 IR-positive bearings; the defect onset is unknown; the contact angle is assumed 0; the speed columns could not be verified independently for B07-B17; only 100 evenly spaced snapshots per end are used; the loads (static and dynamic) also change between snapshots and are not used; the accelerometer is a housing sensor with a 0.5-10 kHz (3 dB) range, so the 10 kHz band edge sits at the sensor's limit; results are not comparable with other papers.
