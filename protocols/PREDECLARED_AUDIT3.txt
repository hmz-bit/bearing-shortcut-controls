PREDECLARED: audit round 3, answering open methodological questions about the controls (items F-01, F-04, F-05, F-06, F-07, F-08). Written before any number of parts E to K was computed. Not to be changed afterwards; later changes go in dated ADDENDA below.
Nature: ALL analyses are DESCRIPTIVE (no decision rule except the metadata threshold in part F). Nothing here is a primary endpoint; the primary endpoint of any confirmatory run (lock-box dataset) is defined in that run's own pre-declaration. These analyses were chosen after exploratory results (audit round 2 and earlier probes) existed; this is stated, not hidden. No model is tuned. No PU evaluation bearing is used for any new design decision. All frozen models use the existing configuration (results/tier1/chosen_config_t_mad.json via scripts/phase2/p2common.py; variants base and rowz_drop of scripts/phase2/variants.py), the primary random forest of scripts/rf/rfcommon.py (PARAMS_PRIMARY, and PARAMS_U as "rfu"), and the existing split files. Intervals: paired bearing-level cluster bootstrap, B = 2000, seed 20261029, stratified by cluster label type (scripts/audit/audit2_ab.py machinery). The sanity rule of audit round 2 applies (window-level means recomputed first; deviation > 0.05 stops that analysis).

PART E (F-01): UORED per label. Window level, existing predictions (base, rowz_drop, B1, RF) plus the DC-removed random forests of part H (rf_dm, rfu_dm). For each label (inner, outer) separately, mean AUROC over the 100 splits (splits where either class is empty skipped, count reported) for these negative sets:
  E1 all negatives (the original task);
  E2 early-life negatives only (cls H = state 0);
  E3 FAFNIR-matched negatives only (negatives restricted to bearings 6 to 20; the NSK 6203ZZ bearings are 1 to 5, per the dataset descriptor);
  E4 stage-matched negatives (positives restricted to state 2; negatives = state 2 windows of the other classes);
  E5 E3 and E4 combined.
  The inner label is reported but not interpreted (the inner class is the NSK bearing model). Differences with intervals for the outer label: rowz_drop - base, rowz_drop - B1, rowz_drop - rf, rowz_drop - rf_dm, base - B1.

PART F (F-04): PU metadata-only control including the recording DC offset. Same random forest (PARAMS_U, random_state 42), same Vieira evaluation splits 5 to 104, same windows as the PU cache (scripts/audit/audit2_c.py run_pu). File-level quantities from results/b1/signals_meta.csv matched to the cache by file name: DC offset = raw_sum / n_raw, record length n_raw. Feature sets: F1 condition only (reproduces 50.0); F2 DC offset only; F3 DC offset and record length; F4 condition, DC offset and record length. Threshold written in advance: 56 (as in round 2). Reported per label as well as macro.

PART G (F-04, model side): do the neural inputs react to the PU recording DC cue? Existing PU predictions of base, rowz_drop and B1 (Vieira's released logits). Damage score of a unit = mean over its windows of max(s_inner, s_outer). Per evaluation split, AUROC over units of "damaged versus healthy" for two subsets: G-high = damaged bearings with high DC (KA04, KA15, KA16, KA22, KI14, KI16, KI17, KI18, KI21) against healthy bearings; G-low = damaged bearings with healthy-like DC (KA30, KI04) against healthy bearings. Mean over splits where both groups are present; also the per-bearing mean over splits of the share of test healthy units that score below the bearing. Only two bearings are in G-low: stated limitation. If the neural inputs used the DC cue, G-low would be near 50 while G-high is high.

PART H (F-05): random forest on UORED with the window mean removed. Rebuild the 20 features of scripts/rf/rfcommon.py window_features for the 2220 UORED windows (same file order and window starts as scripts/rf/build_features.py build_uored: 420000-sample csv, resampled by the same function, hop 10500) after subtracting each window's mean (rf_dm, rfu_dm). Check: the 15 spectral columns equal the stored ones (max abs difference reported) and row order equals the cache. Run the 100 UORED splits exactly as scripts/rf/run_rf.py (no tuning). Report macro and per-label, with the E1 to E5 negative sets.

PART I (F-07): CWRU channel-matched contrast as the reported CWRU contrast. Window level, existing predictions of base, rowz_drop, B1, RF; in each split only windows whose sig_loc equals the channel that holds that split's test healthy windows are kept (as in an earlier probe). Macro-AUROC means and the differences rowz_drop - base, rowz_drop - B1, rowz_drop - rf with intervals.

PART J (F-06, condition): XJTU-SY leave-one-condition-out. Folds: test = all five bearings of one operating condition (1, 2, 3), train = the ten others. Models: base, rowz_drop (seed 7000 + condition, frozen configuration, 40 epochs, as the XJTU runs), rf, rfu. B1 is not run (its pipeline needs the crop bank and is not part of this round: stated limitation). Metrics per fold: macro and per-label AUROC on all held-out windows (stage-confounded, as in the original task) and on the stage-matched set (negatives restricted to faulty-stage windows of bearings without the label). Descriptive point values only (3 folds, 5 bearings each).

PART K (F-06, stage-free fault type): XJTU-SY and Paderborn run-to-failure, faulty-stage windows only (stage == "faulty") in training AND test, so a life-stage detector scores 50 by construction. The existing 100 splits per dataset (results/xjtu/splits.csv, results/rtf/splits.csv), same seeds as the original runs (seed = split). Models: base, rowz_drop (frozen), rf, rfu (primary settings), and a metadata reference (random forest on condition id for XJTU-SY, set speed and sampling-rate group for RTF, faulty-stage windows only). Mean over splits where both classes exist for the label (count reported), per label and macro; differences with intervals as in the other parts (rowz_drop - base, rowz_drop - rf, rowz_drop - metadata reference). Windows of bearings with both defects (XJTU B1_5, B3_2) are positive for both labels as in the original labels.

Not done in this round (stated): B1 on parts J and K; a learning curve; repeated-training bootstrap (training-set variance); UORED within-NSK stage task (5 bearings); per-file UORED speed deviation (F-13); any new dataset (a separate search for further datasets is documented outside this repository).
Outputs: results/audit3/SUMMARY.md and json files; scripts scripts/audit/audit3_*.py; no existing file is modified.

ADDENDUM 1 (written before the B1 run of part K, no B1 number of part K existed): B1 (WDCNN on the fixed-Hz envelope spectrum) is added to part K for XJTU-SY and Paderborn run-to-failure, because it is the published-recipe baseline. Recipe, epochs, batch size, learning rate, gain augmentation and crop handling exactly as in scripts/xjtu/run_b1.py and scripts/rtf/run_rtf_b1.py; the only changes are that training and test windows are restricted to stage == "faulty" and that the training-set standard deviation is computed from those training windows. Same splits, same seeds (seed = split), same skip rule (splits where a label lacks a class in the training or test faulty windows are skipped). Script scripts/audit/audit3_b1_k.py; outputs results/audit3/pred_k_{xjtu,rtf}_b1.parquet. The contrasts rowz_drop - b1 and base - b1 are added with the same bootstrap.
