RANDOM-FOREST BASELINE ON CWRU, UORED-VAFCLS, XJTU-SY AND THE PADERBORN RUN-TO-FAILURE DATA. Written before any random forest was trained on any of these data. Not to be changed afterwards. Any later pipeline error: fix, rerun everything, report both versions.

Purpose: the cross-dataset comparison so far used one baseline family (B1, a WDCNN on the fixed-Hz envelope spectrum). This adds a second, shallow baseline family: a random forest on hand-crafted features (the "B3" feature definition of the PU experiments: 5 time-domain statistics plus 15 broadband envelope log-SNR values). On PU the existing shallow baselines are B2 (random forest on the 15 features of the source benchmark study) 69.72 and B3 (this feature set) 66.76; they are not rerun. Nothing about LF-PNCN or B1 is changed; the existing prediction files are only read.

PREDICTION (stated before the result, not a result): none for the ranking. The only expectation is that the random forest, being given no order resampling, will be at or below the neural methods on datasets with speed variation (Paderborn run-to-failure) and may be competitive on constant-speed sets (UORED, CWRU). If it beats rowz_drop on some dataset this is reported as such.

FEATURES (20 per window; computed from the same raw 1-s window that the LF-PNCN tensor of that dataset is computed from; same speed f_r and bearing geometry as the dataset's LF-PNCN cache):
 1-5. time statistics of the window: rms, peak-to-peak (max - min), kurtosis (Pearson, fisher=False), skewness, crest factor (max|x| / rms).
 6-20. broadband envelope log-SNR: Butterworth band-pass of order 4 (zero-phase, sosfiltfilt) from 500 Hz to min(10000, fs/2 - 1) Hz; squared analytic envelope with the mean removed; one-sided FFT magnitude divided by the window length; median m and 1.4826 x MAD s of the spectrum over the bins 1 Hz .. 9500 Hz (at fs = 12 kHz this is every bin from 1 Hz up to Nyquist); log10(1 + max(0, E - m) / (s + 1e-12)); for each of the three modes (outer race f_o with modulation 0, inner race f_i with modulation f_r, rolling element f_b with modulation f_c) and each harmonic h = 1..5 the MAXIMUM of this normalised spectrum within +-Delta of h x f_mode, Delta = max(0.03 h f_mode, 1.2 f_modulation). This is the code of work/scripts/build_cache.py (functions time_stats and broadband_logsnr) generalised only by passing fs and the bearing geometry as arguments (the original hard-codes the PU values). Feature order: time statistics, then f_o harmonics 1-5, f_i harmonics 1-5, f_b harmonics 1-5.
 Per-dataset inputs (identical to the LF-PNCN caches, see the dataset pre-declarations):
  CWRU: fs 12 kHz, 1-s windows, hop 3000 samples, f_r = nominal speed of the load condition, geometry by signal location (drive end 6205-2RS z=9 d=7.94 D=39.04; fan end 6203-2RS z=8 d=6.746 D=28.50), 144 waveforms, 5328 windows.
  UORED-VAFCLS: fs 42 kHz, accelerometer column, 1-s windows, hop 10500 samples, f_r = 29.75 Hz for all files, geometry z=8 d=6.77 D=28.50, 60 files, 2220 windows.
  XJTU-SY: horizontal channel, first 25600 samples of each selected snapshot resampled to 42 kHz with resample_poly(105, 64) (the offset-0 window of the LF-PNCN cache), f_r = nominal speed of the condition folder, geometry z=8 d=7.92 D=34.55.
  Paderborn run-to-failure: accHorizRear_A, first 1 s of each selected snapshot, times 10 g/V, resample_poly to 42 kHz, f_r of the selection table (measured speed if within 3% of the set speed, else set speed), geometry z=19 d=3.18 D=35.5, 3038 windows.
 The windows are rebuilt from the raw files; before any model is trained the rebuilt LF-PNCN tensor of a random sample of at least 20 windows per dataset is compared with the stored tensor (maximum absolute difference below 1e-4) and the dataset metadata arrays (labels, bearing, stage, file number) are compared with the stored ones, so that the rows are identical to the existing prediction files.

CLASSIFIER (fixed now, no tuning of any kind, no use of test bearings for any choice): sklearn MultiOutputClassifier over the two labels [inner, outer], each a RandomForestClassifier with n_estimators = 200, max_features = "log2", criterion = "log_loss", max_depth = 24, min_samples_split = 15, min_samples_leaf = 18, ccp_alpha = 0.0265, no class weights, random_state = 42 for every split, n_jobs = 4. These are exactly the settings used for B2 and B3 on PU (taken from the source benchmark study, Table 17, selected there on PU data with the 15-feature set). No feature standardisation (not needed for trees). Score of a window = predicted probability of class 1 for the label. Because forest probabilities contain many ties, all AUROC values (point estimates, bootstrap) are tie-aware (average rank / half credit), checked against sklearn's roc_auc_score with sample weights.
 SENSITIVITY VARIANT (declared now, reported for every dataset, NOT a decision criterion, chosen without looking at any result): "RF-U" = the same classifier with unpruned scikit-learn defaults except n_estimators = 200 and max_features = "sqrt" (criterion gini, max_depth None, min_samples_split 2, min_samples_leaf 1, ccp_alpha 0), random_state = 42. Purpose: the primary settings were selected by others on a different data set and feature set and carry a strong cost-complexity pruning, so a second reading guards against a handicapped baseline. The primary RF is the declared one for all decision rules; if RF-U turns out better it is reported but does not replace the primary.

SPLITS, LABELS, SCORING ROWS (identical to the existing runs; training windows and test windows are the same rows as the LF-PNCN and B1 runs, so the comparison is paired window by window):
  CWRU: the 100 evaluation splits of the benchmark study (runs 3..52 x scenarios DE and FE), train and test membership from the waveform_id lists of data/splits/cwru/eval; labels inner and outer of the split metadata; the same asserts as in run_cwru.py (no shared waveform, no shared faulty group, no shared healthy bearing).
  UORED-VAFCLS: the 100 splits run_5..run_104 of the benchmark study (8 test bearings of 20), labels inner = recordings I_k_1, I_k_2, outer = O_k_1, O_k_2.
  XJTU-SY: work/results/xjtu/splits.csv (100 splits, 10 train and 5 test bearings), snapshots and labels of work/data/xjtu/xjtu_windows.npz (healthy end 0, faulty end with the Table 3 labels of the dataset authors).
  Paderborn run-to-failure: work/results/rtf/splits.csv (100 splits, 11 train and 6 test bearings), snapshots and labels of work/data/rtf/rtf_windows.npz.
 Metric: per split, pooled-window AUROC of the inner score and of the outer score over all test windows (same definition as the dataset's own pre-declaration); Macro = mean of the two; mean over the 100 splits.

STATISTICS (same as the dataset analyses): paired bearing-level cluster bootstrap, B = 2000, numpy default_rng(0), the same strata and the same multiplicity draws as the analyze script of each dataset (CWRU: clusters = faulty bearing groups and the healthy configuration clusters "H_" + group, strata = healthy clusters, IR groups, OR groups, B groups; UORED: 20 bearings in 4 strata of 5; XJTU-SY: strata = 5 IR-positive, 8 OR-only, 2 cage-only bearings; Paderborn run-to-failure: strata = 5 OR-positive, 12 other bearings), weighted-AUROC fast path (made tie-aware for the random forest and verified against sklearn), 95% percentile intervals, splits with an undefined AUROC skipped per replicate. The AUROC of base, rowz_drop and B1 is recomputed with the same code from their existing prediction files; it must reproduce the published values (it is a check, not a new result).

PRE-STATED DECISION RULES (reported whatever the outcome), on Macro-AUROC:
 R1 (transfer of the baseline): the RF bootstrap 95% lower bound > 50.
 R2 (each neural method against the random forest): for each of rowz_drop, base, B1 the difference (method minus RF) is SUPPORTED if > 0 with the 95% CI lower bound > 0; INCONCLUSIVE if the point estimate >= 0 and the CI includes 0; NOT SUPPORTED if the point estimate < 0. Additionally, if the CI upper bound is < 0 the label "RF significantly ahead" is attached. The +6 point threshold of the written protocol is reported as met or not met on the point estimate for rowz_drop minus RF.
 R3 (the sentence "rowz_drop does not lose to a simple shallow baseline"): holds on a dataset if rowz_drop minus RF is SUPPORTED or INCONCLUSIVE and fails if it is NOT SUPPORTED.
 Per-label (inner, outer) differences and per-scenario results (CWRU) are descriptive.
 DESCRIPTIVE FOR THE TWO RUN-TO-FAILURE SETS (XJTU-SY and Paderborn run-to-failure; no decision rule): (a) the stage-only reference detector (score = window comes from a faulty life stage, computed with the same splits and rows) is recomputed and the RF is reported against it; (b) the stage-matched analysis (negatives restricted to the faulty-stage windows of bearings that lack the label; positives unchanged) with the same bootstrap as the late-life-negatives analysis of the dataset analyses and the point estimates and leave-one-negative-bearing-out robustness of work/scripts/audit/stage_matched_robustness.py, for RF, RF-U, base, rowz_drop and B1; (c) per-bearing AUROC for every inner-positive and outer-positive bearing (all negatives and late-life negatives). For UORED the existing stage-only value (state > 0: 70.0) is quoted, not recomputed.
 No hyperparameter, feature or variant is changed, added or removed after seeing results. The label-permutation and whole-bearing permutation controls of the dataset analyses are NOT repeated for the random forest (not part of this task); this is a stated limitation.

KNOWN LIMITS AND CAVEATS (stated in advance): the primary RF hyperparameters come from another study's tuning on PU data and are not tuned here (no tuning on any dataset, which may handicap or favour the forest); the feature set uses the known fault frequencies and the dataset's nominal or measured speed, so it carries the same speed assumptions as LF-PNCN (UORED constant 29.75 Hz, CWRU nominal, XJTU-SY nominal, Paderborn measured/set); on CWRU only 12 kHz is available, so the band is 500-5999 Hz; time-domain statistics (rms, peak-to-peak) are scale-sensitive and can carry life-stage or configuration information on run-to-failure and CWRU data, so a high RF score on these sets can reflect shortcuts in the same way as for the other models; the windows and labels inherit all caveats of the dataset pre-declarations (life-stage label construction on XJTU-SY and Paderborn run-to-failure, unknown defect onset, artificial faults on CWRU, 18 faulty bearings on CWRU, window overlap within bearings); the forest has no random-crop augmentation and no early stopping, unlike B1; results are not comparable with other papers.
