B1 (WDCNN ON THE FIXED-HZ ENVELOPE SPECTRUM) ON CWRU. Written before any B1 model was trained on CWRU. Not to be changed afterwards.

Purpose: third dataset for hypothesis H2 (LF-PNCN family versus B1). Same signals, 5328 windows (1 s at 12 kHz, 75% overlap, 37 per signal), labels, splits, scoring rows and seeds as the LF-PNCN runs in PREDECLARED_CWRU.txt (work/data/cwru/cwru_windows.npz, work/scripts/cwru/run_cwru.py). Nothing in the LF-PNCN results or code is modified.

B1 RECIPE, read as TEXT from Vieira et al.'s configs (never executed, never unpickled): configs/experiment/cwru/eval_envelope.yaml plus the front end in src/data/transforms/signal_representations.py (get_envelope, array_filter, bandpass_filter) and signal_processing/power_cepstrum.py (get_fft):
  - model WDCNN (own implementation work/scripts/b1/wdcnn.py) with n_in = 6000 and 3 outputs [inner, outer, ball] (num_class 3), BCE-with-logits on all three labels; the scored columns are inner and outer. Ball label = faulty-signal windows of ball-fault groups (group type "B"); healthy-signal windows are 0 for all three.
  - envelope spectrum (sampling_rate 12000, cutoff [500, 6000], order 12): because 6000 / 6000 = 1, array_filter takes its second branch and applies a 12th-order Butterworth HIGH-PASS at 500 Hz (zero-phase sosfiltfilt, padlen 6, padtype even), not a band-pass; then |Hilbert|, mean removed, one-sided |FFT|/n with bins >= 1 doubled. A 12000-sample window gives 6000 bins at 1 Hz spacing. This literal behaviour of their code is reproduced on purpose.
  - training: Adam lr 1e-2, batch size 32, 30 epochs, drop_last, last epoch used, no validation; each training signal is drawn dataset_multiplier = 5 times per epoch, each draw = one random 1-s crop (crop_size 12000) + a scalar gain |N(1, 0.3)| (the envelope is homogeneous of degree 1, so |g| is exact); normalisation_strategy none (no division by a training-set std).
  - training signals per (run, scenario) = the waveform_ids of train_<scenario>_run_<run>.parquet, test windows = all 37 windows of each waveform in test_<scenario>_run_<run>.parquet.
  - seed = run for scenario DE, run + 1000 for scenario FE (as the LF-PNCN runs); torch seed and numpy generator both from it.
DEVIATIONS (declared in advance):
  1. Random crop start positions are restricted to the 0.25-s grid of the 37 windows per signal (envelope-spectrum bank precomputed once for all 5328 windows), the same approximation as for B1 on UORED. The original draws a continuous random start.
  2. The bank is computed on the full, fixed windows; with normalisation none the scale of the input is the raw sensor scale.
  3. Test scoring uses all 37 overlapping windows per signal (the LF-PNCN rows), not the original non-overlapping windows.
  4. Own re-implementation of WDCNN and of the front end (on PU it was about 3 points above the published B1 on 6 validation splits).
  5. GPU training with cudnn.deterministic; Vieira used their own framework and seeds.

SPLITS AND METRIC: Vieira's CWRU evaluation splits, runs 3..52 x scenarios DE and FE = 100 splits, each trained once. Per split window-pooled AUROC for inner and outer, Macro = mean of the two, mean over splits. Analysis (new script, same unit definition and the same bootstrap draws as work/scripts/cwru/analyze_cwru.py): paired cluster bootstrap B = 2000, seed 0, 95% percentile intervals, clusters = faulty bearings (group) and healthy configurations ("H_" + group), strata = inner groups (6), outer groups (6), ball groups (6), healthy clusters (18); weighted AUROC fast path checked against sklearn. Compared: rowz_drop versus B1 and base versus B1, plus the already published base versus rowz_drop for context. Descriptive: per-bearing AUROC for B1 and results by scenario.

PRE-STATED DECISION RULES (reported whatever the outcome), for each of rowz_drop - B1 and base - B1 on Macro-AUROC: SUPPORTED if the difference > 0 and the 95% CI lower bound > 0; INCONCLUSIVE if the point estimate >= 0 and the CI includes 0; NOT SUPPORTED if the point estimate < 0. The literal H2 threshold (difference >= +6 points) is additionally reported as met or not met on the point estimate. No hyperparameter of B1 or of the LF-PNCN family is changed after seeing results. If a pipeline error is found, it is fixed and ALL B1 results are rerun and both versions reported.

CAVEATS stated in advance: artificial EDM faults; 12 kHz; only 18 faulty bearings; two bearing locations (DE and FE) share one fixed-Hz representation; healthy-cluster definition may understate healthy-side dependence; CWRU signals can identify the experimental configuration, so high scores can reflect shortcuts for every method; Vieira's CWRU recipe (lr 1e-2, multiplier 5) was probably tuned by them on CWRU, which favours B1; deviation 1 may slightly disadvantage B1; the high-pass reading of the cutoff is taken from their code and not confirmed by them; results are not comparable with Vieira's CWRU numbers (label set differs).
